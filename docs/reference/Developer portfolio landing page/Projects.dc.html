01 CLI · Node

promptic

Notes that live in your terminal, with an AI that has actually read them. One plaintext folder is the only source of truth — no database, no crawling, nothing to sync.

Started as a shell alias in 2024. Now the thing I open first every morning.

$ npm i -g promptic

02 Web · TypeScript

storymark

Storybook, but for Markdown. Point it at a folder and get a browsable, live-reloading workbench for your docs — no config file, no framework opinions, no build step to learn.

Built in a weekend by cutting themes, plugins and config. That version is the one people use.

$ npx storymark ./docs

03 CLI · TypeScript

confseal

An .env manager for people who have twelve of them. Encrypt, share and switch environment files per project — and never paste a secret into chat again.

Written after losing a staging config for the third time. Age-based encryption, no accounts.
